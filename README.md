# 下周七 · 蓝色手帐网页 Skill

一套把「蓝色手帐」视觉语言应用到 HTML 网页、教程步骤页和知识卡片页的设计 Skill。

核心特点：天空蓝与奶白背景、轻纸张质感、圆角卡片、便利贴、胶带、手写线条、手机截图与清楚的信息层级。页面默认适配手机，不允许左右滑动。

## 主要文件

- `SKILL.md`：AI 使用时读取的核心规则
- `references/style-guide.md`：详细视觉与网页实现规范
- `examples/blue-journal-web-template.html`：确认过的 HTML 视觉母版
- `examples/*.jpeg`：3 张原始风格参考图

## 调用示例

> 使用「下周七 · 蓝色手帐」把这份内容做成手机端 HTML 教程页。

> 参考蓝色手帐网页母版，做一个不会左右滑动的 3:4 步骤页面。

最短定义：

> 清透蓝白底色 + 轻手帐细节 + 海报式信息层级 + 手机端可靠适配。
